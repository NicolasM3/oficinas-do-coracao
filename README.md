# Oficinas do Coração · Protótipo Interativo

> Projeto desenvolvido para a disciplina de **Interação Humano-Computador (IHC) — USP**.

Este repositório contém o protótipo interativo e os arquivos de design da aplicação **Oficinas do Coração** (Lojinha do Coração · artes e criatividade).

---

## 📱 Telas Implementadas

1. **01 Home**: Lista de oficinas com filtros de público (*Adulto / Infantil*), vagas, datas e valores.
2. **02 Detalhes da Oficina**: Informações detalhadas de data, horário, local, vagas, valores, itens inclusos e descrição.
3. **03 Inscrição**: Formulário de inscrição com campos para participante, responsável e telefone/WhatsApp.
4. **04 Confirmação**: Tela de sucesso e protocolo com status pendente de confirmação.
5. **05 Painel da Equipe (Admin)**: Gestão de vagas, ocupação visual com bolinhas e status (*Publicada*, *Lotada*, *Rascunho*).
6. **06 Cadastro de Nova Oficina**: Formulário de criação de nova atividade.
7. **07 Gestão de Inscritos**: Listagem de participantes por oficina com abas de filtro interativas (*Todas*, *Pendente*, *Confirmada*, *Cancelada*).
8. **08 Perfil**: Painel com histórico, contadores de oficinas e dados cadastrais.
